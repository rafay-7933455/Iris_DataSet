### About Code🧮:

* I have worked on the very popular and famous DataSet Iris

  * Reason to use: Small dataset (150 rows, 5 columns)
  * To get info about iris datset visit this: [Iris DataSet](https://www.kaggle.com/datasets/uciml/iris) 🪻
* There are two files:

  * Linear_Regression.py (Actual Code File)
  * Linear_Regression.ipynb (Jupyter NoteBook File)
* Both the files contain the same code. To understand better, Jupyter NoteBook File is recommended.
* To run the code:

  | Step | Command                                                                                |
  | ---- | -------------------------------------------------------------------------------------- |
  | 1.   | Locate the file                                                                        |
  | 2.   | Open the respective folder in terminal                                                 |
  | 3.   | To install the python if not (optional) type "pip install python" and press _Enter key_ |
  | 4.   | To install requirements type "pip install -r requirements.txt" and press _Enter key_    |
  | 5.   | Finally to run the code type "python Linear_Regression.py" and press _Enter key_      |
